-----------Project Overview

StudyRhythm is a machine learning–powered web application that predicts a student’s learning consistency risk based on their study patterns.
The system analyzes daily and weekly study behavior to identify early signs of irregular preparation and provides actionable feedback to help students stay on track.

-----------Problem Statement

Students often lose consistency in their study routine without realizing it, which can lead to poor performance, stress, and reduced learning outcomes.
StudyRhythm addresses this by predicting the risk of preparation inconsistency early, allowing students to take corrective measures before performance is affected.

-----------Features

Daily study logging for multiple subjects

Automatic weekly aggregation of study patterns

Subject-wise analysis for imbalance detection

Prediction of consistency risk level: Low, Medium, or High

Actionable feedback for improving study habits

Fully web-based application with interactive UI

-----------Technologies Used
->Frontend

HTML – Forms and structure

CSS – Responsive design and styling

JavaScript – Feature computation, risk prediction, and UI logic

->Machine Learning

Python – Dataset handling, model training

Libraries: pandas, numpy, scikit-learn

Logistic Regression – Main model for risk prediction

Optional: Decision Tree – For explainable predictions

-----------How It Works

Daily Input – Students log daily study activity, including subjects studied, study hours, and breaks.

Weekly Feature Calculation – JavaScript aggregates daily logs into weekly features.

ML Prediction – Using trained model weights, JavaScript predicts learning consistency risk.

Output & Feedback – Risk level and suggestions are displayed to the student.

-----------Input & Output
->Input

Daily student input includes:

Subjects studied

Time spent per subject

Total study hours

Number of breaks

Self-rated focus level

->Output

Learning Consistency Risk: Low / Medium / High

Feedback / suggestions to maintain or improve study rhythm

Machine Learning Approach

Model trained in Python using Logistic Regression

Features derived from study patterns:

Study days per week

Average study hours

Missed study days

Longest streak

Subject-wise imbalance

Model weights exported to JavaScript for prediction in the web application

-----------Dataset

Self-generated behavioral dataset

Daily logs aggregated to weekly features

Unique dataset ensures originality and interview discussion material

No public datasets used
